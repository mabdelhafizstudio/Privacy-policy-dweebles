# Privacy Policy — Dweebles: The Holdout

Privacy policy for the iOS game **Dweebles: The Holdout** (bundle ID `app.dweebles.survival`) by MOUD Labs.

The policy lives in [`index.html`](index.html). Turn on GitHub Pages (Settings → Pages → deploy from `main`, root folder) to get a public URL for App Store Connect.

## What the policy is based on

A scan of the `dweebles-backrooms` repo (commit `31b37d8`, Nov 3, 2026) found:

- **Game Center**: sign-in (display name and player ID) and 2–4 player co-op through `GKMatch`, peer-to-peer gameplay sync, no chat
- **Local storage only**: settings and best round in `UserDefaults`
- **None of these**: third-party SDKs, analytics, ads, tracking, in-app purchases, or permission prompts (camera, mic, location, and so on)
- **External links**: Sketchfab and Creative Commons credits

**Update the policy** if you add leaderboards, achievements, IAP, analytics, chat, or any server.

## App Store privacy label

With the current build, **Data Not Collected** is accurate. Game Center data is handled by Apple, not by you.
